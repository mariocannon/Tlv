The code changes every time it's tapped.

Inside each tag is an NXP NTAG 424 DNA chip, the same family used for secure access cards. On every tap it signs a fresh, one-time code with a key that never leaves the chip.

A counterfeiter can copy the link, or print a look-alike sticker. What they can't do is make a new code. The moment an old one turns up again, the shopper sees a warning and you get an alert.

What you get as a brand

A check page in your colours
Shoppers see your name, the product and batch, and a link to your shop. No app to download: any phone with NFC opens it.
Every scan, live
When and roughly where each tag was checked, and how many times. Useful well beyond fraud: you learn where your product actually ends up.
Alerts that matter
A reused link, a tag scanned in two cities within an hour, or a tag we've never seen. Each one lands on your dashboard.

Questions

Do shoppers need an app?

No. Android phones with NFC and iPhone XS or newer read the tag straight away and open the check page in the browser.

Can someone clone the chip?

Each tag gets its own keys when we encode it, and the chip won't give them up. Copying what a tag sends only copies one old code, and an old code shows up as a copy.

What if someone peels a tag off and moves it to a fake?

Use tamper-evident tags, which break when removed. The dashboard also flags a tag that's scanned in two places too far apart to be the same item.

What do you record about shoppers?

The time of the scan, the result, and a rough location from the phone's time zone. No names, accounts or exact locations.

How do the tags go on?

As a sticker on the label or cap, or built into a hang tag or card. They're about the size of a coin and work through paper and plastic, though not directly on metal.
